# 뮤지컬 가사 뷰어

노래방에서 MR을 틀어 놓고 폰·노트북으로 가사를 보는 오프라인 웹앱.

- 모드: 들고 보기(스크롤) / 내려놓기(가로·큰 글씨·자동 넘김) / 갤럭시북(가로·세로 자동)
- 파트 색: 공용 · 남 · 여 (배역 표시로 자동 구분)
- 한글 해석: 줄마다 또는 통째로 붙여넣어도 자동 짝짓기, 짝 맞추기 화면으로 수정
- 타이밍 녹음: MR/원곡 파일 또는 스톱워치(유튜브 등)로 줄 시작 시점 찍기
- 홈 화면에 추가하면 인터넷 없이 열림, 화면 꺼짐 방지

**이 저장소에는 가사가 들어 있지 않습니다.** 가사는 각자 기기에만 저장되며
(PC 폴더 연결 또는 묶음 파일 가져오기), 앱은 외부로 어떤 통신도 하지 않습니다.
